# 🛍️ Mall Customer Segmentation using K-Means Clustering

## 📊 Project Overview

This project implements customer segmentation for mall customers using **K-Means Clustering**, an unsupervised machine learning algorithm. The goal is to group customers based on their **Annual Income** and **Spending Score** to identify distinct customer segments for targeted marketing strategies.

### 🎯 Key Objectives
- Identify distinct customer segments based on spending behavior
- Optimize marketing strategies for each segment
- Provide data-driven insights for business decisions

## 📈 Dataset Description

The dataset contains information about mall customers including:

| Feature | Description |
|---------|-------------|
| **CustomerID** | Unique ID assigned to each customer |
| **Gender** | Gender of the customer (Male/Female) |
| **Age** | Age of the customer |
| **Annual Income (k$)** | Annual income of the customer (in thousand dollars) |
| **Spending Score (1-100)** | Score assigned based on customer behavior and spending nature |
